## Caso de prueba 1

**ID:** TC-001

**Título:**

Registro exitoso de usuario

**Objetivo:**

Validar que un usuario puede registrarse correctamente.

**Precondiciones:**

- La aplicación está disponible.
- El usuario no tiene una cuenta registrada.

**Datos de prueba:**

Correo:
usuario@test.com

Contraseña:
12345678

**Pasos:**

1. Abrir la aplicación.
2. Seleccionar Registrarse.
3. Ingresar correo.
4. Ingresar contraseña.
5. Presionar Crear cuenta.

**Resultado esperado:**

La cuenta es creada exitosamente.

**Resultado obtenido:**

Pendiente.

**Estado:**

Pendiente.

**Notas/Evidencias:**

Pendiente.
