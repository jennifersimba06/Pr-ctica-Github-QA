# Casos de prueba - Historia 5: Realizar pedido

## Caso de prueba 1

**ID del caso:** TC-009

**Título:** Pedido realizado correctamente

**Objetivo:** Validar que un pedido pueda confirmarse exitosamente.

**Precondiciones:**
- Usuario autenticado.
- Existen productos en el carrito.

**Datos de prueba:**
Método de pago simulado.

**Pasos:**
1. Abrir el carrito.
2. Revisar productos.
3. Confirmar pedido.
4. Seleccionar método de pago.
5. Finalizar compra.

**Resultado esperado:**
El sistema genera un número de orden y confirma el pedido.

**Resultado obtenido:**
Pendiente.

**Estado:**
Pendiente.

**Notas/Evidencias:**
Pendiente.

## Caso de prueba 2

**ID del caso:** TC-010

**Título:** Confirmar pedido con carrito vacío

**Objetivo:** Verificar que el sistema impida realizar pedidos sin productos.

**Precondiciones:**
- Usuario autenticado.

**Datos de prueba:**
Carrito vacío.

**Pasos:**
1. Abrir el carrito.
2. Presionar "Confirmar pedido".

**Resultado esperado:**
El sistema informa que el carrito está vacío.

**Resultado obtenido:**
Pendiente.

**Estado:**
Pendiente.

**Notas/Evidencias:**
Pendiente.
